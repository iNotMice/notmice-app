# Техническое Задание (ТЗ): MVP Платформы N=1 Локального и Международного Датасета Биомаркеров

> **Архив.** Рабочий документ — [TZ_v2.1_AGREED.md](TZ_v2.1_AGREED.md). Этот текст оставлен как история и не задаёт текущую работу.

## 1. Общие сведения и позиционирование
- **Название проекта:** Probanda / NotMice (пока рабочий заголовок)[cite: 1, 8]
- **Позиционирование:** Оператор курируемого лонгитюдного датасета N=1-самонаблюдений биомаркеров крови[cite: 1, 3].
- **Главная цель MVP:** Построить работающий сквозной пайплайн за 28 дней[cite: 1, 3].
- **Лицензирование:** Код — AGPL-3.0, Схемы данных и словари — CC-BY-4.0, Экспорт датасета — CC0.

## 2. Ключевые принципы и архитектурные ограничения
1. **Privacy First (Минимизация ПДн по GDPR):** Оригиналы PDF/изображений лабораторных анализов НЕ ХРАНЯТСЯ на диске[cite: 1, 3].
   - Файл принимает сервер в оперативную память (`in-memory`).
   - Вычисляется SHA-256 хеш документа.
   - Извлекаются биомаркеры (OCR / Vision API).
   - После валидации и подтверждения пользователем оригинал уничтожается из памяти[cite: 1, 3].
2. **Provenance (Происхождение данных):** Каждое извлеченное значение содержит метаданные: кто внес, дата забора, название лаборатории, версия парсера, факт подтверждения пользователем[cite: 1, 3].
3. **Псевдонимная аутентификация:** Вход по seed-фразе (recovery phrase) без обязательной привязки e-mail или телефона на старте[cite: 1, 3].

## 3. Модули MVP
- **Модуль 1: Инфраструктура и Схема БД** (FastAPI, PostgreSQL / SQLAlchemy 2.0 async, Alembic, Docker Compose).
- **Модуль 2: Прием и парсинг результатов**
  - Прием PDF (`pdfplumber`) или сканов/фото (`Claude API Vision` с `cache_control` и `tenacity`).
  - Извлечение базовых 9 маркеров PhenoAge + 11 наиболее частых биомаркеров.
- **Модуль 3: Стандартизация и LOINC-маппинг**
  - Приведение названий к справочнику LOINC (напр., Альбумин -> 1751-7)[cite: 1, 5]. Unmapped показатели падают в очередь на ручную размещение[cite: 1].
- **Модуль 4: Расчет PhenoAge**
  - Модуль расчета биологического возраста по методике М. Левин[cite: 1, 3, 5]. Выделена в чистую функцию, покрыта юнит-тестами[cite: 1].
  - Обязателен дисклеймер: исследовательской индекс, не медуслуга[cite: 1].
- **Модуль 5: Публичный Data API & CC0 Export**
  - Реализация спецификации OpenAPI 3.1 (только чтение, rate-limit)[cite: 1].
  - Экспорт датасета в CSV/Parquet с генерацией файла `datasheet` (Datasheets for Datasets)[cite: 1].
- **Модуль 6: Контентный веб-сайт (Astro)**
  - Статический сайт: Главная, Хартия данных, Методология PhenoAge, Раздел для лабораторий, Открытый API[cite: 1].

## 4. Что НЕ входит в MVP (Non-Goals)

- Telegram-бот[cite: 1].
- Хранение оригиналов медицинских документов[cite: 1, 3].
- Токеномика и крипто-механики[cite: 1, 3, 5].
- Прямые врачебные назначения и диагнозы[cite: 1, 3].

## 5. Главный сквозной сценарий (Definition of Done к 10 октября)
Пользователь регистрируется по seed-фразе → загружает PDF бланка анализов → проверяет и подтверждает распознанные цифры → получает расчет PhenoAge → включает тумблер публичности профиля → видит свои обезличенные данные в публичном API и CC0-выгрузке[cite: 1].
