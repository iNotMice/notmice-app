# Личный кабинет участника — функционал и архитектура

**Дата:** 05.10.2026 · **Основа:** [PROPOSAL_PERSONAL_CABINET.md](./PROPOSAL_PERSONAL_CABINET.md) (согласовано Андреем 03.10), приоритеты 1–2.
**Не входит:** ИИ-пояснения (этап 4), сбор страны и других новых атрибутов (этап 3, нужны согласие и DPIA), любые оценки здоровья, тренд-алерты и рекомендации.

## 1. Что видит участник

Раздел «Кабинет» в шапке и по адресу `/account`. Гостю показывается объяснение, что хранится в кабинете, и кнопки входа.

| Раздел | Адрес | Что внутри |
|---|---|---|
| Сводка | `/account` | Аккаунт (дата создания, способ входа, число устройств); история (число анализов, период, лаборатории, повторно измеренные показатели); последний индекс Левина и описательное изменение с предыдущим; каких показателей индекса не хватает в последнем анализе; последние значения **всех** сопоставленных показателей (20 в словаре, а не только 9) с отметкой «вне интервала бланка»; журнал; состояние согласий и публикации; скачивание своей копии |
| Мои анализы | `/account/tests` | Все подтверждённые бланки, новые сверху; по каждому: все значения, название как в бланке, значение и единица как в бланке, интервал бланка; переход в индекс; удаление одного анализа |
| Показатели | `/account/markers` | Существующие графики показателей и индекса (бывшая «История показателей») |
| Журнал | `/account/journal` | Существующий журнал препаратов, сна, активности |
| Данные и согласия | `/account/data` | Существующая страница согласий, публикации, выгрузки и удаления |
| Вход и защита | `/account/security` | Способ входа; смена пароля (с проверкой текущего, выход на других устройствах); число устройств и «выйти на всех других»; выход; ссылка на удаление |

## 2. Правила формулировок

- Кабинет **описывает** данные (числа, даты, сколько раз измерено) и ничего не оценивает: нет «лучше/хуже», «риск», «норма», нет связи записей журнала с изменениями показателей.
- Отметка «вне интервала» сравнивает значение только с интервалом из того же бланка (`outside_printed_interval`), как и раньше.
- Тексты проходят оба гейта: `npm run check:copy` и `app/tests/test_advisor_copy.py` («раздел 3»).

## 3. Архитектура

**Бэкенд (FastAPI, без миграций БД):**

| Слой | Файл | Что делает |
|---|---|---|
| Домен | `app/domain/cabinet_summary.py` | Чистая функция `summarize_cabinet`: порядок по дате сдачи (или дате подтверждения), точки индекса, последние значения по каждому показателю, повторы, несопоставленные названия, журнал |
| Домен | `app/domain/accounts.py` | `OwnCredential`, `AccountSecurity`, ошибки `PasswordNotSetError`, `CurrentPasswordError` |
| Сервис | `app/services/cabinet.py` | `CabinetService.overview`: читает анализы, журнал, согласия и вход, считает индекс тем же движком, что история |
| Сервис | `app/services/accounts.py` | `security_overview`, `change_password` (проверка текущего пароля, Argon2id, выход на других устройствах), `sign_out_other_sessions` |
| Репозиторий | `app/repositories/users.py` | `credential_for_user`, `count_live_sessions`, `revoke_other_sessions` |
| API | `app/api/cabinet.py`, `app/api/accounts.py` | `GET /api/v1/accounts/me/cabinet`, `POST /api/v1/accounts/me/password`, `POST /api/v1/accounts/me/sessions/revoke-others` |

- Все три эндпоинта требуют сессию и отдают только данные владельца. Хеши паролей, хеш документа и дайджесты сессий в ответ не попадают (это проверяет тест).
- Смена пароля ограничена по IP и по аккаунту (существующие лимитеры). Неверный текущий пароль — 400, аккаунт по фразе — 409, короткий новый — 422.
- Текущая сессия при смене пароля сохраняется, остальные закрываются.

**Фронтенд (React):** `src/components/cabinet/*` (оболочка, сводка, анализы, вход и защита), клиент `src/api/cabinet.ts`, адреса в `src/routes.ts`, тексты в `src/i18n/messages/{en,ru}/cabinet.ts` (немецкий пока показывает английский).

## 4. Тесты

- `app/tests/test_cabinet_summary.py`: правила сводки (порядок, индекс, повторы, интервалы, журнал).
- `app/tests/test_cabinet_api.py`: 401 без сессии, только свои данные и никаких секретов, смена пароля (неверный текущий, короткий, успех, выход других устройств), «выйти на других», аккаунт по фразе.
- `src/routes.test.ts`, `src/i18n/format.test.ts`: адреса кабинета и форматирование дат и чисел.

## 5. Что дальше (не в этой версии)

1. Объединение бланков ОАК и биохимии одной даты в одну панель — без этого индекс не считается у многих участников из РФ/СНГ.
2. Нейтральные сводки динамики по показателям с порогами, обоснованными вариабельностью измерений (этап 2 предложения).
3. Страна проживания — только после цели обработки, согласия и DPIA (этап 3).
4. ИИ-пояснения — только после юриста (этап 4).
